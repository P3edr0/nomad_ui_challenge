---

### ▶️ Executando o projeto

```bash
# Instalação do projeto
flutter pub get

# Executar em modo desenvolvimento  
flutter run --profile --dart-define-from-file=.env/dev_env.json

# Build para produção
flutter build apk --release --dart-define-from-file=.env/dev_env.json
```
